# Timing material

This release provides the benchmark script for new measurements, not the
original per-architecture timing logs. Run it with a new output directory as
described in the main README. It produces `metadata.json`,
`per_architecture.csv`, `timing_summary.csv`, `summary.json` and checkpoints.

Actual times depend on hardware, software and system load. New measurements
must not be described as the original run reported in the manuscript.
No output files have been reconstructed from screenshots. The older time columns in
`training/graph_metrics_same_216.csv` concern a broader set of metrics and are
not the timing experiment reported in Table 1.
